## [0.1.0] - 2026-08-17

### Added

- Initial Meridian LLMOps platform: FastAPI document Q&A with hybrid retrieval (dense + BM25 RRF), sufficiency checks, and configurable LLM providers.
- React/Vite web UI.
- Docker Compose for Qdrant, ingestion and evaluation scripts.
- Documentation: README, runbook, ADRs.
