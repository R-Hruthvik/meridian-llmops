# 0001. Python, FastAPI, and Async LangGraph for Core Agent Platform

We chose Python 3.11+ with FastAPI, Pydantic v2, and async LangGraph as the core language and orchestration framework. Python provides the richest ecosystem for enterprise AI, LLMOps, guardrails, and evaluation libraries (LiteLLM, NeMo Guardrails, DeepEval, Langfuse SDK), while LangGraph enables stateful cyclic graph execution essential for self-healing loops.
