# Progress journal

Append one entry per round: what, evidence, what's next. This is how a future session
(or a restarted one) resumes without re-deriving anything.

## Format

```
### <date> — <short title>
- change: <what actually changed, file:line>
- evidence: <tests, scans, screenshots, measurements>
- next: <file:line + intent, or backlog item>
```
