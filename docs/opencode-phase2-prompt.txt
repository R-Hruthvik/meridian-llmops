SPECIFICATION 1: `src/components/chat/useRagChat.ts` & `src/components/chat/useRagChat.test.ts`
---------------------------------------------------------
Export interface `ChatTurn`:
```typescript
import type { SearchResult, VerificationSummary } from '../../types/api';

export interface ChatTurn {
  id: string;
  query: string;
  createdAt: number;
  status: 'idle' | 'retrieving' | 'generating' | 'verifying' | 'complete' | 'error';
  activeStage?: {
    name: 'retrieving' | 'generating' | 'verifying';
    status: 'started' | 'complete';
    timings_ms?: Record<string, number>;
  };
  answer: string;
  sources: SearchResult[];
  verified: boolean;
  refusal: boolean;
  degraded_reason?: string | null;
  answer_status?: 'answered' | 'insufficient_context' | 'unverified' | 'refused';
  timings_ms: Record<string, number>;
  execution_time_ms: number;
  verification?: VerificationSummary | null;
  error?: { message: string; status?: number };
}

export interface UseRagChatOptions {
  tenantId?: string;
  initialTurns?: ChatTurn[];
}
```

Export hook `useRagChat(options?: UseRagChatOptions)`:
- State:
  - `turns: ChatTurn[]`
  - `activeTurnId: string | null`
  - `isLoading: boolean`
  - `activeTurn: ChatTurn | null` (computed from activeTurnId)
- Functions:
  - `submitQuery(queryText: string, queryOptions?: { topK?: number; maxCycles?: number; enforceGuardrails?: boolean }): Promise<void>`:
    - Generates a unique `id` (e.g. `crypto.randomUUID()` or timestamp-based fallback).
    - Creates a new turn with status `'retrieving'`, empty answer, empty sources.
    - Uses `AbortController` (stores controller in ref for cancellation).
    - Attempts SSE POST to `/v1/query/stream` with headers `{ 'Content-Type': 'application/json', 'X-Tenant-Id': tenantId }`.
    - If `response.ok` and `response.body`:
      - Read SSE stream chunks line by line. Parse `event: ...` and `data: ...`:
        - `event: stage`: updates `activeStage` and `status` to `'retrieving' | 'generating' | 'verifying'`.
        - `event: token`: updates `status` to `'generating'`, appends `data.delta` to `answer`.
        - `event: retrieval_complete`: updates `timings_ms`.
        - `event: verification_complete`: updates `verification` and `verified` (`data.status === 'citations_ok' || data.status === 'supported'`).
        - `event: error`: sets `error: { message: data.message }`, `status: 'error'`.
        - `event: done`: updates `answer: data.answer || turn.answer`, `answer_status: data.answer_status`, sets `status: 'complete'`.
    - Fallback: If fetch throws or returns non-200 / not ok, fall back to `api.query(...)` from `../../services/api`. Update turn with response fields (`answer`, `sources: response.sources || response.source_chunks`, `verified`, `refusal`, `degraded_reason`, `answer_status`, `timings_ms`, `execution_time_ms`).
    - If fallback also fails, set turn `status: 'error'`, `error: { message, status }`.
  - `abortCurrentQuery()`: aborts current controller, marks in-flight turn as complete or cancelled.
  - `clearTurns()`: resets `turns` to `[]`.
  - `removeTurn(id: string)`: filters out turn by id.

In `useRagChat.test.ts`:
- Test submitting query with successful SSE stream tokens and stage progression.
- Test fallback to `api.query` when SSE endpoint is unavailable.
- Test aborting query mid-stream.
- Test clearing turns and removing turn.
